# OpenFlex Neo - Basic App Template

A minimal OpenFlex Neo application with reactivity.

## Features

- ✅ ActionScript 4 with reactivity
- ✅ Counter example
- ✅ Hot reload ready
- ✅ Browser runtime included

## Quick Start

```bash
# Install dependencies (if needed)
npm install -g openflex-neo

# Compile
openflex build src/main.as4

# Or use watch mode
openflex-watch src/

# Open in browser
open index.html
```
