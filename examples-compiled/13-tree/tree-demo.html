OpenFlex Neo - Tree Component Demo

Features Demonstrated:
  • dataProvider - Hierarchical array data source
  • labelField - Field to display as node text
  • childrenField - Field containing child nodes (default: "children")
  • iconField - Field for custom icons per node
  • labelFunction - Custom formatting function for labels
  • selectedIndex - Two-way binding for selected node path
  • defaultOpen - Auto-expand all nodes on load
  • change / itemClick - Selection events
  • itemOpen / itemClose - Expand/collapse events

Try: Click the triangles to expand/collapse folders. Click nodes to select them.
