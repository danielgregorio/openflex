OpenFlex Neo - Item Renderers Demo

Features Demonstrated:
  • labelFunction on <List> - Custom formatting function for list items
  • labelFunction on <DataGridColumn> - Custom formatting per column
  • Currency formatting with toFixed() and toLocaleString()
  • Date formatting with toLocaleDateString()
  • Visual indicators (stock status, star ratings)
  • Calculated fields (years of tenure)

Note: The labelFunction receives (item, index) and returns a String.
