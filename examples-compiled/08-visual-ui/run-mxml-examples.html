🚀 Features do OpenFlex Neo MXML

  • Sintaxe MXML declarativa (como Adobe Flex)
  • Componentes Neo: VBox, HBox, Panel, Button, Label, TextInput, CheckBox, Repeater
  • Data Binding automático com {expression}
  • Reatividade granular com @reactive e @computed
  • Event handlers: click="{functionName}"
  • Two-way binding para TextInput
  • Repeater para loops de arrays
  • Estilos CSS inline e fx:Style
  • Compilação para Web Components nativos
  • Zero dependências no runtime
// Exemplo MXML: <Application xmlns:fx="http://openflex.dev/core" xmlns="http://openflex.dev/neo"> <fx:Script> @reactive var count: Number = 0; @computed var doubled: Number { return count * 2; } function increment(): void { count++; } </fx:Script> <VBox gap="{20}"> <Label text="Count: {count}" /> <Label text="Doubled: {doubled}" /> <Button label="Increment" click="{increment}" /> </VBox> </Application>
