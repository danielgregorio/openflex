🚀 Sobre OpenFlex Neo MXML

Framework declarativo com sintaxe MXML (como Adobe Flex) e sistema de reatividade granular. Compila para Web Components nativos com zero dependências no runtime.

Features: @reactive signals • @computed properties • Data binding {expression} • Event handlers • Repeaters • Two-way binding • Componentes Neo (VBox, HBox, Panel, Button, etc)
