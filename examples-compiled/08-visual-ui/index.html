🔧 Como Funcionam

1. Reatividade (Signals):

const count = new Signal(0);  // Estado reativo

createEffect(() => {
    display.textContent = count.value;  // Atualiza automaticamente
});

count.value = 5;  // UI atualiza sozinha!

2. DOM Manipulation:

button.addEventListener('click', () => {
    count.value++;  // Muda o estado
    // UI atualiza automaticamente via effect!
});
